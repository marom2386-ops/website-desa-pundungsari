Panduan WordPress

Paket tema dan konten awal Desa Pundungsari, siap dipasang ketika hosting WordPress tersedia.

Status saat ini: situs publik berjalan di GitHub Pages. Tema ini adalah paket WordPress yang sebenarnya, tetapi WordPress belum terpasang secara daring karena hostingnya belum tersedia.

1. Unduh paket yang diperlukan

  • Tema Pundungsari untuk WordPress (.zip)
  • Konten awal untuk diimpor (.xml)
  • Lambang Kabupaten Lumajang (.png)

2. Siapkan hosting

Gunakan hosting yang mendukung WordPress dengan PHP, MySQL atau MariaDB, serta HTTPS. Gunakan WordPress versi stabil yang masih didukung, sekurang-kurangnya versi 6.6 untuk tema ini. Akun hosting dan domain sebaiknya berada dalam pengelolaan desa.

Hosting adalah tempat WordPress dijalankan. Domain adalah alamat website. Pembelian, pemilihan penyedia, dan pemasangan ke akun hosting belum termasuk dalam pekerjaan ini karena akun hosting belum tersedia.

3. Pasang dan aktifkan tema

  1. Pasang WordPress melalui panel hosting.
  2. Masuk ke dasbor WordPress pada alamat website tujuan, biasanya melalui /wp-admin.
  3. Buka Tampilan → Tema → Tambah Tema → Unggah Tema.
  4. Pilih berkas pundungsari-wordpress.zip, pasang, lalu aktifkan.

4. Impor konten awal

  1. Buka Perkakas → Impor → WordPress. Pasang pengimpor resmi apabila diminta.
  2. Pilih konten-pundungsari.xml, lalu petakan penulis ke akun pengelola desa.
  3. Pilih unduh dan impor lampiran untuk mengambil lambang dari situs GitHub saat ini, atau unggah lambang secara manual ke Media.
  4. Jalankan impor satu kali agar tidak menambahkan konten ganda.

5. Atur identitas dan navigasi

  1. Di Pengaturan → Umum, isi judul situs Desa Pundungsari, bahasa Indonesia, dan zona waktu Jakarta.
  2. Di Pengaturan → Membaca, pilih halaman statis: Beranda untuk halaman utama dan Berita Desa untuk halaman pos.
  3. Di Pengaturan → Permalink, pilih Nama pos, lalu simpan.
  4. Di Tampilan → Editor, buka bagian Header. Pilih blok Logo Situs dan gunakan lambang Lumajang yang telah diunggah.
  5. Periksa menu navigasi. Tema memakai daftar halaman bawaan WordPress; sesuaikan urutannya dan hindari tautan Beranda ganda.
  6. Periksa nomor telepon, email, jam pelayanan, nama perangkat, serta isi profil sebelum pengumuman resmi.

6. Kelola berita dan halaman

Untuk berita: buka Pos → Tambah Baru, isi judul dan naskah, tambahkan foto kegiatan yang benar, periksa pratinjau, lalu terbitkan. Untuk profil, layanan, pemerintahan, dan kontak: gunakan menu Halaman.

Tampilan beranda dan kepala/kaki halaman dapat disesuaikan melalui Tampilan → Editor. Tema memakai blok bawaan WordPress; tidak membutuhkan pembuat halaman berbayar.

Buat akun tersendiri untuk setiap petugas melalui Pengguna. Gunakan peran Editor untuk petugas pengelola isi; akun Administrator digunakan untuk pengaturan situs. Penulis dapat digunakan untuk petugas yang hanya menulis berita.

7. Lengkapi informasi publik

Angka kependudukan dan APBDes belum dimasukkan ke paket publik karena data sumber belum cocok. Periksa catatan verifikasi dalam proyek. Setelah disahkan, masukkan angka beserta periode dan sumbernya, lalu unggah dokumen publik yang sudah diperiksa.

Empat berita awal mempertahankan ringkasan pada situs sebelumnya. Lengkapi naskah dan dokumentasi berdasarkan kegiatan nyata; paket ini tidak menambahkan kutipan, foto kegiatan, atau angka rekaan.

8. Pindahkan alamat setelah siap

  1. Uji website tujuan melalui HP dan komputer, termasuk menu, pencarian, gambar, tautan WhatsApp, dan akun petugas.
  2. Siapkan pencadangan dan pembaruan rutin WordPress, tema, serta plugin yang dipakai.
  3. Setelah alamat WordPress final aktif, arahkan pengunjung dari situs GitHub ke alamat baru.
  4. Umumkan satu alamat resmi yang akan digunakan masyarakat.
