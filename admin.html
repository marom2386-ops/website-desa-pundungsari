Pengelolaan website

Panel admin demo dinonaktifkan demi keamanan. Tidak ada login PIN yang aman pada situs statis GitHub Pages.

Website publik tetap dapat dilihat. Pengelolaan konten sementara dilakukan melalui repositori GitHub oleh pengelola yang memiliki akses.

Panel admin baru hanya akan diaktifkan setelah tersedia autentikasi di server, hak akses petugas, validasi masukan, dan penyimpanan database yang aman.
